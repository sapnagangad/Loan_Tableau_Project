# Loan Analysis – Tableau Project

## 🏦 Project Overview
This project features an interactive **Tableau dashboard** that analyzes **loan data** to evaluate approval trends, repayment behavior, and overall lending performance.

## 🎯 Objectives
- Analyze loan applications and approval rates  
- Identify default and repayment trends  
- Assess risk across loan types and customer segments  
- Support data-driven lending decisions  

## 🛠 Tools & Technologies
- **Tableau** – Data visualization and dashboard development  
- **Excel / CSV** – Data cleaning and preprocessing  

## 📊 Key Insights
- Loan approval and rejection trends  
- Default rates and repayment behavior  
- Performance comparison across loan categories  

## 📂 Project Structure
- Tableau dashboard file  
- Loan dataset  
- Project documentation  

## 🚀 How to Use
1. Download the Tableau file from this repository  
2. Open it using **Tableau Desktop** or **Tableau Public**  
3. Use interactive filters to explore loan insights  

## 📌 Conclusion
This project demonstrates how loan data can be visualized effectively to assess risk, monitor performance, and improve lending strategies.
